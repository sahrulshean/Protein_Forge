PROTEIN FORGE — VERSI GODOT 4

CARA MENJALANKAN DI GODOT
1. Ekstrak ZIP ini.
2. Jalankan Godot 4.6.x (proyek diuji dengan Godot 4.6.3).
3. Pada Project Manager, klik Import.
4. Pilih project.godot pada folder utama hasil ekstraksi.
5. Buka proyek, lalu tekan F5 atau tombol Run Project.
6. Klik Mulai merakit.

Versi ini memakai GDScript dan antarmuka native Godot. Tidak memerlukan Python,
browser, server, plugin, koneksi internet, atau instalasi dependensi tambahan.
Tidak perlu export templates untuk menjalankan proyek dari editor.

ISI GAME
- Enam ronde membaca kodon mRNA dan merakit peptida lima residu.
- Skor, penjelasan, tabel 64 kodon yang dapat dicari, rekor, dan main ulang.
- Rekor disimpan lokal di user:// milik Godot.

BERKAS UTAMA
- project.godot: proyek yang di-import ke Godot.
- godot/scenes/main.tscn: scene utama.
- godot/scripts/main.gd: antarmuka permainan.
- godot/scripts/game_session.gd: data kodon dan aturan permainan.
- godot/tests/: pengujian native Godot.

README.md berisi penjelasan lebih lengkap. Versi web Python sebelumnya tetap
tersedia di src/, tetapi tidak digunakan untuk menjalankan versi Godot.
